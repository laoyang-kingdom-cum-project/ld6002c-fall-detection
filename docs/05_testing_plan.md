# 05 测试计划

## 软件测试

- mock reader 能输出 `RadarFrame`
- mock 流程中会出现 `fall_detected=True`
- 连续跌倒信号超过确认时间后进入“确认跌倒”
- 短暂跌倒信号不会直接确认跌倒
- CSV 日志包含每一帧和系统状态
- Streamlit 页面能读取日志并显示最新状态

## 现场测试场景

1. 无人：雷达检测区域内无人。
2. 正常走动：人在检测区域内缓慢走动。
3. 坐下：老人从站立变为坐下。
4. 躺下：老人正常躺下，观察是否误报。
5. 模拟跌倒：用安全方式模拟快速倒地或跌倒姿态。
6. 误报测试：被子、椅子、宠物或其他移动物体造成的干扰。

## 记录建议

每次测试应记录：

- 场景名称
- 雷达安装高度和角度
- 串口原始帧样例
- `RadarFrame` 解析结果
- 状态机输出
- 是否触发报警
