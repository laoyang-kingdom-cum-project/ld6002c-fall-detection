# 03 串口协议说明

当前项目不写死 LD6002C 的真实串口协议，因为还没有协议文档和原始帧数据。

第一版采用如下策略：

- `serial_reader.py` 只负责打开串口、读取 bytes。
- `ld6002c_parser.py` 维护内部 `bytearray` 缓冲区。
- `LD6002CParser.feed(data)` 接收串口 bytes。
- 如果没有解析到完整帧，返回 `None`。
- 真实协议到位后，再将完整帧转换为 `RadarFrame`。

## 待补充内容

设备到货后，根据《LD6002C 跌倒检测串口协议文档》补充：

- 帧头
- 帧长度
- 命令字
- 数据区字段
- 校验和或 CRC
- 异常帧丢弃
- 缓冲区重同步

## 为什么不能猜协议

串口协议如果猜错，可能导致字段含义错误、误报或漏报。课程项目中应保留原始帧样例，并用测试验证解析器行为。
